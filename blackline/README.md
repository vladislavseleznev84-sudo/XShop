# BLACKLINE — сайт барбершопа

Демонстрационный проект: независимый барбершоп, эстетика fashion-editorial + брутализм.
Единственный «фирменный» приём — слово BLACKLINE, разрезанное линией; остальное сдержанно.

> **Всё содержимое — демо.** Адрес, телефон, почта, часы, имена мастеров, цены, длительности и «свободные окна»
> вымышлены. Фотографии — стоковые (Unsplash), домен `blackline.example` — заглушка.
> **Запись — не интеграция.** Форма проверяет данные и формирует заявку, но она сохраняется только в `localStorage`
> браузера и никуда не отправляется. Интерфейс сам говорит об этом пользователю.

## Запуск

```bash
npm install
npm run dev          # разработка
npm run build        # tsc + сборка + пререндер статического HTML
npm run preview      # посмотреть сборку
npm test             # юнит-тесты логики записи (vitest)
npm run e2e          # e2e в Chromium: десктоп + iPhone 14, axe, сценарий записи (нужен build)
```

## Стек и решения

| Что | Чем | Почему |
| --- | --- | --- |
| Сборка | Vite 8, React 19, TypeScript (strict) | компонентная архитектура без лишнего рантайма |
| Стили | CSS Modules + токены в `styles/global.css` | нет зависимостей, нет конфликтов селекторов |
| SEO | пререндер (`entry-server.tsx` → `scripts/prerender.mjs`), JSON-LD `HairSalon`, OG, robots, sitemap | контент есть в исходном HTML, а не только после JS |
| Шрифты | Noto Serif Display (заголовки), Onest (интерфейс), IBM Plex Mono (подписи) — self-host, latin + cyrillic | нужна кириллица; ось ширины даёт «сжатый» вордмарк |
| Картинки | `sharp`: монохромный грейд, AVIF + WebP × 4 размера, LQIP | единый тон, ~6 МБ на 13 кадров, ленивая загрузка |
| Анимация | один rAF-цикл прокрутки (`lib/scroll.ts`), IntersectionObserver, CSS | без анимационных библиотек; уважает `prefers-reduced-motion` |

JS: ~88 КБ gzip, CSS: ~9 КБ gzip.

## Структура

```
src/
  components/        секции и UI (Hero, Manifesto, Services, Gallery, Lightbox, Barbers, Location, Footer…)
    booking/         форма записи: шаги, чек, логика
  data/              контент: site, services, barbers, gallery (+ images.manifest.json — генерируется)
  hooks/             useReveal, useParallax
  lib/               чистая логика: format, phone, schedule, booking, scroll, bookingStore  (покрыта тестами)
  styles/global.css  токены, шрифты, система появления
scripts/             fetch-images, optimize-images, prerender
e2e/smoke.mjs        сквозная проверка
```

## Визуальная система

- Палитра закрыта: `#101010`, `#1C1C1C`, `#E9E5DC`, `#A7A7A2`, `#777777`. Акцентного цвета нет — только свет и тень.
  `#777` используется только для линий и декора: как цвет мелкого текста он не проходит контраст AA.
- Один мотив появления — «шторка» (clip-path слева направо), как движение бритвы. Нет fade-up на каждой секции.
- Тёмные секции чередуются со светлыми «бумажными» (услуги, запись).
- Мобильная версия проектировалась отдельно: двухъярусный вордмарк BLACK / LINE, срез между строками,
  плавающая кнопка записи, поля 16 px (iOS не приближает страницу), `svh`/`dvh`, safe-area.

## Подключение реальной записи

Вся «серверная» часть — одна функция `submitBooking(draft)` в `src/lib/booking.ts`. Замените её тело на запрос
к вашему API/CRM (контракт `BookingDraft → BookingReceipt`), а расписание в `lib/schedule.ts` (`slotsFor`) — на
данные из вашей системы. Остальной интерфейс менять не нужно.

## Что заменить перед боевым использованием

1. Контент в `src/data/*` и JSON-LD/мета в `index.html`; домен в canonical/OG/sitemap.
2. Фотографии: список в `scripts/images.config.mjs`, затем `npm run images:fetch && npm run images:build`
   (или положите свои исходники в `assets-src/<ключ>.jpg` и запустите только `images:build`).
3. Ссылки соцсетей (`data/site.ts`) ведут на главные страницы платформ.
4. Карта — схематичная SVG-иллюстрация, не навигация; подключите реальную карту, когда будет настоящий адрес.

## Проверено

- `npm test` — 16 тестов (форматирование, маска телефона, расписание и часовой пояс салона, валидация, демо-отправка).
- `npm run e2e` — отсутствие ошибок консоли и сетевых сбоев (включая гидратацию), отсутствие горизонтальной
  прокрутки, шрифты и картинки, лайтбокс, мобильное меню, валидация, маска телефона, полный сценарий записи,
  axe-core (WCAG 2 A/AA, serious/critical = 0), `prefers-reduced-motion`.
- Лабораторные замеры (эмуляция iPhone 14, замедление CPU ×4, ~1,6 Мбит/с): FCP ≈ 1,1 с, LCP ≈ 2,4 с, CLS ≈ 0,01.
  Это не Lighthouse; перед релизом прогоните его на реальном хостинге.
